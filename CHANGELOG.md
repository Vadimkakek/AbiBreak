# Changelog

## 0.1.0

Initial public release of AbiBreak.

### Added

- EVM ABI compatibility comparison
- breaking-change detection for removed functions, events, and custom errors
- output and state-mutability change detection
- event indexed/anonymous compatibility checks
- Ethereum function/error selectors and event topic hashes
- tuple and tuple-array canonical signatures
- human-readable, JSON, and Markdown reports
- CI-friendly exit codes
- zero runtime dependencies
- automated tests and GitHub Actions CI
